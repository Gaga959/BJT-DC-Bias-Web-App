# Design — Per-resistor resistance units

Date: 2026-11-17
Status: approved by owner (conversation, 2026-11-17)

## Intent

ให้ตัวต้านทานแต่ละตัวเลือกหน่วยของตัวเองได้ (kΩ / Ω / MΩ) เพื่อกรอกค่าจริง
ได้ตรง ๆ เช่น `RB = 1 MΩ` พร้อม `RC = 2.2 kΩ` และ `RE = 1000 Ω` ในฟอร์มเดียว
โดยยังคงผลการคำนวณเป็น SI เดิมทุกประการ

## Goals

- หน่วยแยกอิสระต่อฟิลด์: `R1`, `R2`, `RC`, `RE`, `RB` (แล้วแต่โหมด)
- ค่าเริ่มต้น `kΩ`; ไม่ส่งหน่วยมา → ตีความเป็น `kΩ`
- ป้ายในวงจรใช้หน่วยของฟิลด์นั้น ๆ ตามที่กรอก
- พิสูจน์ว่าค่ากายภาพเดียวกันที่กรอกต่างหน่วยให้ผลเท่ากันทุกโหมด

## Non-goals

- ไม่เปลี่ยนสมการ/แบบจำลองใน `dc_bias.py`
- ไม่ทำ JavaScript คำนวณหรือแปลงหน่วยฝั่ง client
- ไม่คงช่อง `unit` กลางแบบเดิม (ตัดออก) และไม่ทำ backward compatibility
  เพราะเป็นแอป local ใช้คนเดียว ไม่มีผู้เรียก API ภายนอก

## Anti-goals

- ตัวเลขผลเปลี่ยนจาก A1–A5 เดิม
- หน่วยหนึ่งไปมีผลกับอีกตัวโดยไม่ตั้งใจ
- error ไม่บอกว่าฟิลด์ไหนหน่วยผิด

## Constraints

- HTML/CSS ล้วน, ทำงานออฟไลน์, ไม่มี JS คำนวณ
- `dc_bias.py` รับ SI เท่านั้น (ไม่แตะ)
- ข้อความ UI ไทย หน่วยอังกฤษ; validation ไทยคงที่
- `unittest` เท่านั้น, TDD ทุกพฤติกรรมใหม่
- ฟอร์มต้องพอดีจอ 1366×768 (3 คอลัมน์)

## Approaches

1. **Inline select ต่อฟิลด์ (เลือก)** — `<select name="r1_unit">` อยู่ในแถวเดียวกับ
   ช่องค่า; ลบช่อง "หน่วยตัวต้านทาน" กลาง จบใน HTML ไม่ต้อง JS
2. พิมพ์หน่วยติดค่า (`1M`, `2.2k`) — ต้อง parse ข้อความอิสระ ผิดง่าย
   และไม่เข้าชุดกับ select ที่มีอยู่
3. select ต่อฟิลด์ + ช่องตั้งหน่วยเริ่มต้นทั้งฟอร์ม — เพิ่ม UI ซ้ำซ้อน ไม่มีประโยชน์

## Decisions (owner-approved)

- ชื่อฟิลด์: `<field>_unit` → `r1_unit`, `r2_unit`, `rc_unit`, `re_unit`, `rb_unit`
- ค่าใน select: `kohm`, `ohm`, `mohm`; แสดง `kΩ`, `Ω`, `MΩ`
- ค่าเริ่มต้น/ค่า fallback: `kohm`
- หน่วยผิด → `หน่วยของ <LABEL> ไม่ถูกต้อง` (เช่น `หน่วยของ RC ไม่ถูกต้อง`)
- ลบช่อง `name="unit"` และค่า default `unit` ใน `DEFAULT_FORMS`
- `_to_ohms(raw, unit, label)` คงเดิม; ผู้เรียกส่งหน่วยของฟิลด์นั้น
- ป้ายวงจร: helper กลาง `_unit_symbol(unit)` → `kΩ` / `Ω` / `MΩ`
- ป้าย `aria-label` ของ select: `หน่วยของ <LABEL>`
- ช่องค่าและ select อยู่ใน `.field-input` เดียวกัน; select กว้างพออ่าน
  (`kΩ`/`MΩ`) และช่องค่ายังยืดหยุ่น

## Verification

- Unit tests: `_to_ohms` ครบ 3 หน่วย; label ต่อฟิลด์; select ที่เลือกคงอยู่
- Route tests: หน่วยผสมทุกโหมดให้ผลเท่าฐาน kΩ เป๊ะ (IC/VCE/VE/VB/VC/IE/IB)
- Negative: หน่วยผิดชี้ชื่อฟิลด์; ค่าไม่ใช่ตัวเลขยังขึ้น "เป็นตัวเลข" ก่อน
- Browser: รัน A1–A5 ใหม่ด้วยหน่วยผสม (RB เป็น MΩ, RE เป็น Ω) เก็บภาพ
  `docs/evidence/lab03-a1..a5.png` ทับชุดเดิม และอัปเดต `docs/validation.md`
  (commit SHA + วิธีตรวจ + หมายเหตุหน่วยอิสระ) กับ `README.md`
- เกณฑ์เดิม: |ΔIC| ≤ 0.01 mA, |ΔVCE| ≤ 0.02 V

## Left to the builder

- ความกว้าง/ระยะห่างของ select ใน CSS ให้พอดี 1366×768 และจอแคบ
- จะรวมป้าย `aria-label` เป็นข้อความไทยแบบใด (ให้ตรงชื่อฟิลด์)
- ลำดับการแก้เทสต์เดิมที่ใช้ `unit` กลาง → หน่วยต่อฟิลด์
